# Revenue Leakage Detective

AI-powered merchant revenue leakage investigation platform.

## Structure

- `frontend/`: React + TypeScript + Vite
- `backend/`: Python + FastAPI
- `data/`: Synthetic data for development
- `tests/`: Pytest and frontend tests
- `docs/`: PRD and Architecture documentation

## Setup

### Backend
1. Install dependencies: `pip install -r requirements.txt`
2. Run backend: `uvicorn backend.app.main:app --reload`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
